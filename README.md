# distributed-skills

Skills I hand out in my videos — [Marc Talks to Machines](https://www.youtube.com/@marctalkstomachines).

Each folder is one self-contained skill for Claude Code: the skill file plus the starter
files it needs to run. No installer, no dependencies. Open the folder's README and follow it.

| Skill | From the video | What it does |
|---|---|---|
| [`organize-batch`](organize-batch/) | *3 Levels of Claude for People Who Don't Code* | The standing folder-organization job: proposes before touching anything, executes only on approval, leaves a verifiable record. |

These live on your machine, not in a store. That's the point.
