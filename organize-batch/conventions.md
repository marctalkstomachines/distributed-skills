# conventions.md — rules this job has earned

**If this file is nearly empty, that's correct.** It starts that way on purpose.

This is where corrections become rules. The agent gets something wrong, you correct it in
the moment, and if it's the kind of mistake that would happen again, the correction earns a
line here. The skill reads this file before every run, and these rules override its own
classification instincts — your judgment, written down once, applied every time after.

Don't fill this in ahead of time. You can't predict what it'll get wrong, and rules written
from imagination are worse than none. Let it be wrong first.

## Format

One rule per line, dated, with the mistake that earned it in parentheses:

- <the rule>. (earned <date>: <what the agent did wrong>)

## Rules

- Game mods are not archives. Anything that installs into a specific game goes in
  `Installers\<Game> Mods\`, with its mod manager beside it. (earned 2026-08-12: three
  Baldur's Gate 3 mods were filed under generic Archives — EXAMPLE FROM MY RUN, delete this
  line and let your own corrections fill the list)
